# Polaris / Xiaomi MIX 2S

按 W202DS 的板型树注册，硬件平台为 SDM845，内核选择 7.1-rc1。

- `kernel`：链接 Polaris Linux 板级工程；其内部 `kernel/` 直接固定上游内核。
- `boot`：链接同一远端仓库的 `boot` 分支工程。
- `rootfs`：发行版策略层，等待硬件机制与 profile 迁入。
- `initramfs`：板级早期钩子，等待 7.1-rc1 启动需求确定。
- `desktop`：桌面策略边界，目前不声明桌面可用。

本轮只注册目录，`supported_targets` 为空，所有构建请求在下载或写入构建目录前拒绝。
这避免继承 W202DS 默认的内核、USB 服务或显示硬件策略。完成板级实现并验证后再逐项启用。
本地开发使用相对软链接；子模块声明指向同一 Polaris-linux 仓库的两个分支。
远端初始为空分支，本地骨架需后续发布后，远端子模块才可用于克隆构建。
