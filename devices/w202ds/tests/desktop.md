# W202DS 多 DE 验收

每个 DE 使用独立 rootfs、相同内核与板级固件做对比。记录内核、Mesa、DE、
共享后端版本和具体错误，不能把另一 DE 的通过记录沿用过来。

| 层 | 检查 | 通过条件 |
| --- | --- | --- |
| 共享后端 | `w202-device-controls status` | JSON schema 1；缺失接口为 null，有失败原因；状态与真实硬件一致 |
| 网络 | Wi-Fi/蜂窝开关、保存连接 | 实际切换、原连接配置保留、断线恢复符合预期 |
| 蓝牙 | 开关、重启、配对 | 电源状态恢复且配对记录保留 |
| GNSS | 开启、关闭、接口缺失、其他会话占用 | 服务所有权正确、关闭后释放电源；不干扰 Wi-Fi/蓝牙 |
| 充电 | 模式、协议、充电分离 | 真实读回与请求区分，保护机制有效；无读数不伪造电流 |
| 手电筒 | 开关、亮度、缺失硬件 | 正确读回、关闭可靠、异常可见 |
| 标准输入 | 接键盘、拔键盘、合盖开盖 | SW_TABLET_MODE/SW_LID 正确，无重复/意外动作 |
| DE 会话 | Wayland、触摸、旋转、屏幕键盘 | 当前 DE 的真实行为正确，外接键盘策略符合预期 |
| DE 电源管理 | 空闲息屏、合盖、开盖唤醒 | 按本 DE 设置执行；不借用另一 DE 的补偿脚本 |
| 图形 | Vulkan 离屏结果、窗口呈现 | 分别记录渲染错误与合成器/呈现错误 |

硬件切换可能中断连接或触发息屏，实机测试保留独立恢复通道。
当前实现共用后端、KDE 适配和 GNOME 薄会话入口。GNOME Shell 自定义快捷按钮、
新会话入口的真实用户会话验收仍待完成，不能由离线接口测试推断为已验收。

## Server 霍尔显示策略

`tests/test_server_hall.py` 检查初始开合状态、关闭保持、非盖子事件、丢失事件同步和显示写入失败重试。
`tests/test_userspace.py` 检查 overlay 只进入 Server 包，缺少 ARM64 控制程序时拒绝打包。
实机需分别验证快速合开不息屏、合盖超过两秒息屏、开盖亮屏；合盖期间 SSH 和硬件服务继续运行。
图形桌面不启用本服务，继续由对应 DE 处理盖子动作。
