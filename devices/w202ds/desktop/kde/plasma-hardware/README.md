# 状态和通知快捷控制

`HardwareControls.qml` 将 5G、Wi-Fi、蓝牙、GNSS、平板模式和自动旋转六个横排开关嵌入现有「状态和通知」首页，快充和充电分离嵌入原生电池弹窗。不注册额外托盘入口或弹窗。

后台状态查询不禁用按钮；切换请求串行执行并保留最后一个待处理操作。
平板模式的手动覆盖仅在本次开机有效，键盘插拔恢复自动判断；自动旋转设置独立持久化。

手电筒为单行图标开关与亮度滑条，关闭时仍可拖动。亮度走独立控制请求，
不等待完整硬件状态查询；连续拖动合并待处理亮度，旧查询结果不覆盖新操作或拖动位置。

以桌面用户运行 `python3 install.py` 后重新加载 Plasma。安装器使用用户级系统托盘副本，保留原系统包；不匹配预期结构时拒绝修改。

依赖 KDE 会话适配入口 `/usr/libexec/w202-hardware-controls`（转发到共享 C 后端
`/usr/libexec/w202-device-controls`，再追加旋转和平板模式状态），复用 NetworkManager、BlueZ、GNSS 与充电接口。涉及特权的操作使用现有 Polkit 授权，不修改网络连接配置。

电池弹窗使用 `ChargingItem.qml`，沿用原生电池条目的图标、标题和详情布局，显示模式选择、实际协议、输入与 USB 输出电压电流、电池充放电以及充电分离。Auto 默认开放最高安全配置；PPS 允许协商并保留固定 PD 回退。选择意图只记在运行时，重启后由实际硬件状态决定显示。

没有实测接口的电流显示不可用，协商电流单独标为上限。BC1.2 自动识别仍由驱动负责，目前缺少强制关闭 PD 的接口，菜单中的 BC1.2 因此不可选。

USB 控件位于托盘展开页，支持 OTG/Device/Host 预选、实际数据与供电角色、Device
开关及 ACM/NCM 复选组合。点击应用后通过共享 C 策略入口保存和执行；可能断开
USB 网络/串口。更改预选不代表实际协商完成，实际绑定也不代表主机枚举成功。
